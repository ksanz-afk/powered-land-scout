# Skills

Shared agent skills for this repo. Each folder holds a `SKILL.md`.

| Skill | Use it to |
|---|---|
| `start-work` | Begin any task: pull, read the contract, branch, claim |
| `schema-change` | Change shared tables, types and fixtures in one PR |
| `add-data-source` | Vet and log a new external source before using it |
| `add-demo-county` | Add a county across fixtures and pages |
| `ship-pr` | Check and open a pull request |

Add a skill the second time anyone repeats a multi-step task.
